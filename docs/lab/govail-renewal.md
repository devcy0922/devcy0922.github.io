## 이런 문제를 풉니다

GoVail은 사내 AI 요청이 지나가는 Gateway입니다. 콘솔은 그 Gateway를 쓰는 사람이 **키를 받고, 모델을 써보고, 무엇이 막혔는지 확인하는** 화면입니다.

- 로그인하지 않은 방문자도 소개 화면에서 브라우저 기준 1일 데모 키를 받아 바로 호출해 볼 수 있습니다.
- 로그인은 Keycloak OIDC(PKCE)로 합니다.
- 감사 로그는 막힌 이유를 보안 정책, 컨텍스트 한계, 모델 접근, 라우팅 실패, 연결 종료로 나눠 보여줍니다. 컨텍스트 한계는 보안 차단으로 세지 않습니다.
- engine-process로 실행한 에이전트 세션을 요청 단위로 펼쳐 프롬프트·도구 흐름·종료 사유를 보고 좋음/나쁨 피드백을 남깁니다.

[콘솔 열기 ↗](https://console.govail.cloud)

## 리뉴얼 과정 {#how}

콘솔 저장소의 커밋 기록을 기준으로 정리했습니다. 순서가 실제 작업 순서입니다.

1. **모바일 정합성 (9월 둘째 주)** 관측 화면을 모바일에서 단일 패널로 전환하고, 터치 영역을 40px 이상으로 맞췄습니다. 긴 Trace ID와 JSON이 화면 밖으로 넘치지 않게 했습니다.
2. **계정 경계 (10월 9일)** 관측과 감사 로그를 계정별로 나눠 보이게 하고, 로그인 없이 둘러볼 수 있는 게스트 샌드박스를 붙였습니다.
3. **화면 언어 통일 (10월 9~10일)** 감사와 관측의 타임라인 카드를 하나의 구조로 합치고, 티어 라벨과 메타데이터를 한국어로 정리했습니다.
4. **실행 과정 보이기 (10월 10~14일)** Playground가 엔진 이벤트를 SSE로 받아 왕복(턴)별 진행과 도구 인자 요약을 실시간으로 보여주도록 바꿨습니다.
5. **세션 검토 (10월 15~16일)** 엔진 세션을 요청 단위로 펼쳐 도구 흐름, 루프 타임라인, 프롬프트 조립 신호를 확인하고 품질 피드백을 남기는 화면을 추가했습니다.

## 디자인 원칙

- 흑백 위주, 상태색은 정보일 때만. 장식용 그라데이션과 과장된 수치는 쓰지 않습니다.
- 막힌 요청은 **왜 막혔는지와 무엇을 하면 되는지**를 같은 줄에서 보여줍니다.
- 개발자 화면과 관리자 화면이 같은 구성요소(카드, 타임라인, 배지)를 씁니다.

1. 캡처 촬영과 짧은 GIF(키 발급 → 첫 호출 → 감사 로그 확인)
2. 세션 검토 화면에 피드백 집계 추가
3. 리뉴얼 전후 비교 캡처 정리
