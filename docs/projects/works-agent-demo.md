# works-agent-demo

작업 결과를 주장만으로 판단하지 않고, 실행 과정에서 남은 증거와 검증 결과를 함께 다루는 에이전트 워크플로 데모입니다.

- **상태**: 공개 개발 중
- **저장소**: [devcy0922/works-agent-demo](https://github.com/devcy0922/works-agent-demo)
- **기술**: CSS 중심 인터랙티브 데모

## 방향

에이전트가 무엇을 했는지뿐 아니라 어떤 근거로 완료를 판단했는지 확인할 수 있는 작업 흐름을 실험합니다.
